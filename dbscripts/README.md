# Scripts de banco de dados

Este add-on utiliza `autoDDL = true`, portanto as tabelas e os campos definidos no dicionário de dados são criados automaticamente durante a publicação no Sankhya Om.

Mantenha nesta pasta apenas scripts complementares que não possam ser representados pelo dicionário de dados. Todo script incluído aqui deve ser idempotente e validado primeiro em um ambiente de homologação.
